## explain-diff-html

Generates a rich, self-contained interactive HTML explanation of a code change (diff/branch/PR) — background, intuition, code walkthrough, and a quiz. Includes fixes for quiz bias (options are equal-length and deterministically shuffled, so the correct answer isn't guessable from length or position alone).

Originally based on [Explain Diff](https://gist.github.com/geoffreylitt/a29df1b5f9865506e8952488eac3d524) by [Geoffrey Litt](https://github.com/geoffreylitt).
